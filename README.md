## Structure

This is a Flask web app.
A main page connects to other different pages (different projects).

## prerequisite

1. Install the libraries

```bash
pip install -r requirements.txt
```

2. Environment variable (for the API keys)
   Get your own API key at [ai.hackclub.com](https://ai.hackclub.com/keys)

In PowerShell

```bash
$env:OPENROUTER_API_KEY="your_api_key_here"
```

In Command Prompt

```bash
set OPENROUTER_API_KEY=your_api_key_here
```

If you want it to persist across new terminals in PowerShell

```bash
[System.Environment]::SetEnvironmentVariable("OPENROUTER_API_KEY","your_api_key_here","User")
```

3. For the data extraction file (optional, if you want to test out the python file that web scraps the data for the Netflix Data Analysis, which writes on netflix_data.json)

- Install Google Chrome
- Preferred: no manual driver install with recent Selenium.
  Fallback: install ChromeDriver matching local Chrome major version.

to run:

```bash
python netflix_data_extraction.py
```

4. Connect to the Internet

5. Python 3.10+ (recommended)

6. To run the main project

```bash
set FLASK_APP=app
```

```bash
set FLASK_ENV=development
```

```bash
flask --app main_app.py --debug run
```

Then click on the link (http://localhost:5000) and enjoy.

## Projects

I have put a total of 4 projects on this web app.

1. Netflix Data Analysis

- This is a project on web scrapping and presenting data with AI. In this project, I scrapped the netflix data on the flixpatrol website and made a summary using AI.

2. Instagram Caption Generator

- This a project on generating output with an image input. In this project, I fed an AI an image from the internet and make it generate a caption, simulating an Instagram post.

3. Grammarly Grammar Correction

- This is a project on text analysis and json structuring. In this project, I used AI to analyze a paragraph of text with grammatical mistakes, then output a json structure and output them on a web page, highlighting different mistakes like Grammarly.

4. Duolingo Language Course

- This is a project on language learning with AI. In this project, I used AI to generate a 10-lesson language course for a language of choice, then output the course in a structured format, simulating a Duolingo lesson.

## Netflix Data Analysis

I used Selenium and BeautifulSoup to do web scrapping on a website called flixpatrol (code.txt) and get the data about Netflix.
Since the data of a certain date is already saved in netflix_data.json, users doesn't necessarily have to run netflix_data_extraction.py to get the data. Users can just simply test out the web app directly.

Then using that json file that I web scrapped and gave it to AI to generate a summary about either movies or tv shows (more can be seen in the system promopt text file).

It analyzes the data about Netflix.

## Instagram Caption Generator

Users can input an image link to the website and select its preferences for the Instagram caption.

Then these requirements will be sent to an AI and generates the suitable caption for the Instagram post.

It simulates an Instagram post.

## Grammarly Grammar Correction

Users can input a large paragraph of text that contains grammatical mistakes.

The text will be sent to an AI and it will output a JSON structure.
The JSON structure will be used to present the different mistakes the user's input text. The website will highlight the grammatical mistakes and also suggest how to correct them.

It simulates the functions of Grammarly.

## Duolingo Language Course

Users can select the language they want to practice and have a 10 question quiz of it.

The input language will be sent to an AI and it will generate 10 questions including the answers and choices in a JSON structure.
The JSON structure will then be used to output those questions on the website and allow users to practice.

It simulates a lesson practice in Duolingo.

## Limitations

- The AI responses are generated live as you click, slow Internet or API rate limits will cause timeouts.

- For the instagram caption generator, only publicly accessible image URL are accepted (just copy one on a browser), private or auth-gated URLs will fail.
